ライブラリー/sortedset

概要

本体→https://kuronosu1024.github.io/libs/library/datastructure/sortedset.hpp

ランダムアクセスができるset (実装はAAtree)
イテレータも用意した（してもらった）ので、begin(), rbegin()とかも使えます

コンストラクタ


sortedset<T> st;
  • 型 \(T\) の空のsortedsetを生成します

制約

  • Tは全順序集合である必要があります (比較演算子が定義されている必要があります)

計算量

  • \(O(1)\)

[]演算子


const T st[int i];
  • コンテナの要素のうち、i番目に小さいものの値を返します

制約

  • \(0 \le i \lt n\)
  • 範囲外参照をした場合、T()を返します

計算量

  • \(O(\log n)\)

イテレータの型


sortedset<T> st;
const sortedset<T> cst;

st.begin()  , st.end()   // sortedset<T>::iterator 
cst.begin() , cst.end()  // sortedset<T>::const_iterator 
st.rbegin() , st.rend()  // sortedset<T>::reverse_iterator 
cst.rbegin(), cst.rend() // sortedset<T>::const_reverse_iterator
  • イテレータです 通常のstd::setのと同じ機能です
  • したがって、使い方はそっちを調べるとよいです（説明放棄）

計算量

  • 値のアクセス : \(O(1)\)
  • インクリメント/デクリメント : ならし\(O(1)\)

size


size_t st.size()
  • コンテナの要素数 \(n\) を返します

制約

  • 特にない

計算量

  • \(O(1)\)

insert


void st.insert(T key)
  • コンテナに要素keyを追加します
  • 要素が重複したときは何も起きません

制約

  • 特にない

計算量

  • \(O(\log n)\)

erase


void st.erase(T key)
  • コンテナから要素keyを削除します
  • なかったら何も起きません

制約

  • 特になし

計算量

  • \(O(\log n)\)

find


sortedset<T>::iterator st.find(T key) //stが非constのとき
sortedset<T>::const_iterator st.find(T key) //stがconstのとき
  • コンテナにkeyが含まれているとき、keyを指すイテレータを返します
  • 含まれないとき、st.end()を返します

制約

  • 特になし

計算量

  • \(O(\log n)\)

count


size_t st.count(T key)
  • コンテナに含まれるkeyの個数（0か1）を返します

制約

  • 特になし

計算量

  • \(O(\log n)\)

upper_bound


sortedset<T>::iterator st.upper_bound(T key) //stが非constのとき
sortedset<T>::const_iterator st.upper_bound(T key) //stがconstのとき
  • keyより大きい要素であって最も小さいものを返します
  • keyより大きい要素がなかった時、st.end()を返します

制約

  • 特になし

計算量

  • \(O(\log n)\)

lower_bound


sortedset<T>::iterator st.lower_bound(T key) //stが非constのとき
sortedset<T>::const_iterator st.lower_bound(T key) //stがconstのとき
  • key以上の要素であって最も小さいものを返します
  • key以上の要素がなかった時、st.end()を返します

制約

  • 特になし

計算量

  • \(O(\log n)\)
