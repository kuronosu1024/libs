基本的に自分で使う用に作ったライブラリどもです<br>
動作しないorバグなどあれば何かしらの手段(issues/twitter/discord etc...)で連絡くれると助かる<br>
<br>
このライブラリの基本理念は<br>
① 自分のほしいものを入れる<br>
② 拡張性を頑張る<br>
③ 余裕があれば高速化<br>
<br>
...なので、定数倍の高速化は基本的にしない方針です(拡張性を優先します)<br>
